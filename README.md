# quantitative-trading-exercises

This project contains a series of exercises designed to help individuals learn and practice quantitative trading concepts. The exercises cover various topics, including data analysis, algorithmic trading strategies, risk management, and performance evaluation.

## Getting Started

To get started with the exercises, first clone the repository to your local machine:

```bash
git clone https://github.com/01Joseph-Hwang10/quantitative-trading-exercise
```

Then, install the required dependencies via [uv](https://github.com/astral-sh/uv):

```bash
uv install
```

> [!NOTE]
> If you're not familiar with `uv`, please refer to the [uv documentation](https://docs.astral.sh/uv/)

## Exercises

Exercises live under `notebooks` directory. Each exercise is contained in its own Jupyter notebook, which includes instructions, code snippets, and exercises to complete.
